# DocBook — Project Report (print master)

`DocBook_Project_Report.docx` is the submission copy of the project report, built
from the actual source code of this repository. It runs to about 25 A4 pages
(cover + 4 front-matter pages + 20 numbered pages).

## Before you print

1. Open the file in Microsoft Word (or Google Docs / LibreOffice) and replace every
   field printed in square brackets, e.g. `[NAME OF THE COLLEGE / INSTITUTE]`,
   `[STUDENT NAME]`, `[ROLL NUMBER]`, `[NAME OF THE GUIDE]`, `[SESSION]`.
2. Replace the generic cross-and-circle mark on the cover page with the college logo
   (right-click the image → *Change Picture*).
3. Replace the nine dashed screenshot frames in Chapter 5 with real captures of the
   running application. Keep each image inside the same paragraph so the captions
   stay on the page:

   | Frame | Screen to capture |
   | --- | --- |
   | Fig. 5.1 | Home page with the doctor directory |
   | Fig. 5.2 | Login / sign-up screen |
   | Fig. 5.3 | Calendar with available time slots |
   | Fig. 5.4 | Confirmation message after booking |
   | Fig. 5.5 | Patient dashboard (appointments, reschedule, cancel) |
   | Fig. 5.6 | Doctor dashboard with weekly schedule and time-off |
   | Fig. 5.7 | Doctor confirming / rescheduling an appointment |
   | Fig. 5.8 | Report panel with generated report |
   | Fig. 5.9 | Administrator dashboard |

   The ready-made figures (flowchart, data flow diagram, ER diagram) are in
   `figures/` at full resolution if you ever need to rebuild a page.

4. Update the table of contents last: click inside it and press **F9** (or
   *References → Update Table → Update entire table*). The page numbers in the
   contents and the footer are automatic fields.

## Print and binding instructions for the copy shop

* Paper: A4, 80–100 gsm, single side.
* Print the **cover page on 170–250 gsm card stock** (one extra copy of page 1 if the
  shop wants a laminated front sheet).
* **Thread binding only.** Ask for *thread / hand-sewn binding* (also called
  *section-sewn* or *library binding*), not spiral, not comb, not hard-case.
* The left margin is already set to **1.5 inch (3.8 cm)** so the stitching does not
  eat into the text block; the other margins are 0.9 inch.
* Colour printing is needed only for the flowchart and the screenshot frames;
  the rest is black and white.
